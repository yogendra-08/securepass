Good password habits

  • Use a unique password for every account. Reuse lets one breach unlock many accounts.
  • Never reuse a generated password. Generate a fresh one each time.
  • Use a reputable password manager to store them, so you don't need to memorize each one.
  • Enable multi-factor authentication where available.
  • No server involved. Passwords are generated in your browser and never transmitted.
